# SHIPMIND
ShipMind is an offline Android prototype providing instant, workflow-organized troubleshooting and "how-to" guides for critical shipboard digital systems like ECDIS and AIS.
ShipMind — Supplementary Material
Companion to the IAMUC 2026 paper: Impact of Technostress on Seafarer Wellbeing: Survey Insights and
Mitigation Strategies
Installation
1 On your Android device, go to Settings → Security (or Apps & notifications → Special access) and enable
Install unknown apps for your file manager or browser.
2 Download ShipMind_prototype.apk from this folder to your device.
3 Tap the file and follow the install prompts.
4 Launch ShipMind from your app drawer.
Minimum requirements: Android 10.0 or later. Approximately 25–40 MB free storage. No internet connection
required after install.
Quick tour
• Home — entry point listing supported systems.
• System view — drill into ECDIS, AIS, or other modules to access guides.
• Troubleshooting flows — step-by-step diagnostic paths for common faults.
• How-to guides — task-oriented procedures (e.g., chart updates, route planning).
• Search — keyword lookup across all guides.
A 60-second screen recording (demo_video.mp4) is included in this folder for a visual walkthrough.
Known limitations
• Current build covers all major bridge and engine-room systems at a general level; vessel- and vendor-specific
variants are not yet differentiated.
• Content reflects general shipboard conventions and is not a substitute for vendor documentation or onboard
standing orders.
• The application is offline-only by design; no telemetry or user data is collected or transmitted.
• Some interface elements may render differently across Android versions and screen sizes.
Status and intended use
ShipMind is a research prototype developed in support of the IAMUC 2026 paper submission. It is provided as-is
for academic review and discussion. It is not a certified navigation aid, does not replace official vendor
documentation or operator training, and is not licensed for commercial distribution.
